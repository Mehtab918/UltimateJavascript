Browser Object Model

The browser object model is a model which provides a window object

Important Notes - When we declare variables, objects, and functions globally in javaScript, it also becomes a member of this window object.

  • window.alert(message) – Displays an alert box with a message.
  • window.confirm(message) – Displays a confirmation dialog box with "OK" and "Cancel" buttons.
  • window.prompt(message, defaultValue) – Displays a dialog box asking for user input.
  • window.open(url, target, specs) – Opens a new browser window or tab with the specified URL.
  • window.close() – Closes the current window (only if opened via window.open).
  • window.setTimeout(function, milliseconds) – Executes a function after a specified time delay.
  • window.setInterval(function, milliseconds) – Repeats a function at specified intervals.
  • window.clearTimeout(id) – Cancels a timeout set by setTimeout().
  • window.clearInterval(id) – Cancels an interval set by setInterval().
  • window.scrollTo(x, y) – Scrolls the window to a specific position.
  • window.scrollBy(x, y) – Scrolls the window by a relative amount.
  • window.resizeTo(width, height) – Resizes the window to specified dimensions.
  • window.resizeBy(width, height) – Resizes the window by a relative amount.
  • window.focus() – Brings the window into focus.
  • window.blur() – Removes focus from the current window.
